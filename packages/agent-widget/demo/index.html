Widget host-page harness

Serve this directory and open the page from a real origin:

  1. pnpm --filter @larkup/agent-widget build
  2. cd packages/agent-widget && python3 -m http.server 5599
  3. Add http://localhost:5599 to the agent's allowed origins (Larkup → Settings → Agents → Connect).
  4. Open http://localhost:5599/demo/?agent=<agentId>&host=http://localhost:4567

What to check: the bubble renders with its own font, colours and rounded corners despite the page's rules above; the panel opens and closes smoothly; streaming text appears token by token; and nothing on this page changes when the widget mounts.

Removing the agent query parameter is also a valid test — the widget should log an actionable error and mount nothing.
