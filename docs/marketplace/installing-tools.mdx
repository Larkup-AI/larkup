---
title: 'Installing tools'
description: 'Add an optional tool from the Marketplace.'
icon: 'download'
---

Open **Settings → Marketplace**, choose a tool, and select **Install**. The tool becomes available in the part of Larkup it extends; media tools appear in **Data → Media**.

<Steps>
  <Step title="Review the tool">
    Read its description, supported runtime modes, permissions, and documentation.
  </Step>
  <Step title="Install">
    Larkup installs the package in its isolated tools directory. It does not add dependencies to
    your project package.json.
  </Step>
  <Step title="Choose a runtime">
    Use the tool's settings to choose local processing, Larkup Cloud, or a compatible endpoint you
    operate.
  </Step>
  <Step title="Use it where it appears">
    Return to the relevant Larkup surface, such as Media for a video tool, and start a job.
  </Step>
</Steps>

You can uninstall a tool from the same Marketplace screen at any time. Existing source data is not deleted by uninstalling a tool.
