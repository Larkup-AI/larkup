Larkup Marketplace is where optional capabilities live. A tool can add an indexing workflow, a chat result view, a local runtime, or a compatible cloud service without making the core application heavier for everyone else.

## How tools work

Every tool has a small installable package and a human-readable manifest. The manifest describes what the tool contributes, what permissions it needs, and where it can run. Heavy software such as OCR engines, video codecs, and GPU models stays inside the tool's own Docker runtime.

## Built for sharing

Tool authors can ship a manifest, documentation, versioned package, and runtime configuration together. Installing a shared tool never transfers the author's provider credentials. Each installation connects with its own local runtime, Larkup Cloud account, or custom endpoint.

<Note>
  A tool is removable. Uninstalling it removes its isolated installation and disables its optional
  surfaces without changing your normal Larkup data.
</Note>
