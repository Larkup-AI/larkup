**Larkup** is an open source platform that lets you build a private AI over your own files, websites, databases, and connected tools. Chat with your data, analyze it, or expose it through a live API.

There is no pipeline to configure before you start. Open the app, provide your API key, load content from the Data page, and start chatting. Indexing, the RAG server, and model selection run behind the scenes.

### Who it is for

**Business users** can load documents, connect tools like Notion or Google Drive, and start asking questions without writing code.

**Developers and teams** get a running RAG server with a full REST API, official TypeScript and Python SDKs, and support for AI SDK and LangChain in the same workspace.

### How it works

<Steps>
  <Step title="Enter your API key">
    On first launch you will see an onboarding screen. Paste an OpenAI, Anthropic, or other provider key and Larkup is ready to go.
  </Step>
  <Step title="Load your data">
    Go to the **Data** page and pick a source: upload files, scrape a website, paste text, import media, or connect an integration such as Notion, Google Drive, or Slack.
  </Step>
  <Step title="Start chatting">
    Open the **Chat** page. Larkup indexes your data automatically and grounds every answer in what you loaded. Responses include source citations, embedded video players, inline charts, and more depending on your content.
  </Step>
</Steps>
