Larkup gives you a complete data pipeline out of the box. Crawl entire domains, upload local documents, or paste raw text then track every ingestion job in real time. Everything runs through a single **Data** tab with three views: **Add Data**, **Corpus**, and **ETL Jobs**.

## Adding Data

The **Add Data** tab is your starting point for loading content into the pipeline. You can choose from three ingestion modes:

- **Web Scrape**: Crawl websites by keyword search or direct URL. Powered by Firecrawl, with support for local and cloud modes.
- **Paste Text**: Drop in raw text or a single URL for quick ingestion.
- **Upload Files**: Drag and drop files directly. Supported formats include PDF, Word (`.docx`), Markdown, CSV, JSON, Excel, and plain text.
- **Media**: Upload images, video, or audio. The optional **Video & Audio** marketplace tool also imports direct media URLs, YouTube videos, and playlists (up to 10 items per batch).

### Video and audio indexing

Before an upload or URL import starts, Larkup shows the detected duration, expected processing time, and estimated transcription cost. Transcription and vision pricing depend on the providers selected in **Settings → Marketplace Tools** and **Settings → Models**; local Whisper has no API charge.

Video indexing combines adaptive scene sampling, a reserved dense ending pass, chronological visual analysis, OCR, and timestamped speech. It stores a concise full video summary plus independent timestamped evidence sections, so chat can connect people and events while still retrieving the exact ending, decision, winner, or score. Short edited videos use detailed windows. Long camera and screen recordings use sparse seeked anchors and lightweight keyframe change detection to avoid repeatedly analyzing unchanged frames.

The configured Audio Provider handles speech transcription. There is no silent OpenAI fallback. Deepgram uses Nova 3 and accepts an **Audio language** code such as `ar` or `ar-EG`. With **Auto**, Larkup uses the known source caption language, infers Arabic from an Arabic media title, and otherwise asks Deepgram to detect a supported language. Manual YouTube captions can be used directly. Automatic captions remain a fallback and do not silently bypass the configured provider.

The Media panel persists separate live stages for download, extraction, transcription, visual analysis, note synthesis, and search indexing. Parallel transcription and visual work show their own counts, and embedding reports real processed and total chunks. Completed assets are already embedded and searchable. No separate index build is required.

Use **View Uploads** to index an existing video or audio asset again after changing its provider, language, or analysis settings.

Search retrieves more semantic candidates for media and expands a matching moment with its immediately preceding and following timeline segments. This gives the answering agent enough before → event → after context for questions about outcomes, actions, or a specific scene in a long recording.

After indexing, matching chat sources include an embedded player and seek to the cited time range. YouTube citations also link to the original video at the matching timestamp. Direct URL imports reject private or local network addresses.

## Scraping Configuration

Larkup supports both **local** and **cloud** scraping. You can configure everything from the **Global Settings** panel, no `.env` editing required.

### Local Firecrawl

Click **Launch Web Crawler** in the Add Data tab to connect to the optional local Firecrawl stack. A bearer token is generated automatically, so you can start scraping immediately with zero signup.

The standalone `docker run` image contains only Larkup, so it cannot launch sibling Docker services by itself. To use local crawling with Docker, start the crawler profile from the repository:

```bash
docker compose -f docker/docker-compose-prod.yaml --profile crawler up -d
```

Alternatively, configure a Firecrawl cloud API key in Settings.

### Cloud API Keys

If you prefer the hosted Firecrawl or Serper.dev services, enter your API keys in Global Settings:

- **Firecrawl API Key (Cloud)**: for web crawling in the cloud
- **Serper.dev API Key**: for programmatic Google search ingestion

### Proxy Settings

For organizations that route traffic through a proxy, such as for higher request limits or secure scraping, the settings panel exposes proxy configuration fields:

- **Proxy Server**: e.g. `http://proxy.example.com:8080`
- **Proxy Username**
- **Proxy Password**
