Open **Settings** to configure the active Larkup workspace. Changes apply to Chat, indexing, and the generated server.

## AI Models

Use **Settings → AI Models** to select the providers and models used for embeddings and chat.

<Frame caption="Embedding and chat model settings">
  <img src="/images/new/ai-models-settings.png" alt="AI Models settings with embedding and chat providers" />
</Frame>

### Embedding model

The embedding model turns loaded content and search queries into vectors. Choose a provider, model, and API key, then save the configuration.

### Chat model

The chat model generates answers from retrieved context. It can use the same provider as embeddings or a separate provider and key.

<Note>
  Changing the embedding model requires indexing existing content again so stored vectors use the same model as future queries.
</Note>

## Storage and retrieval

Use **Settings → Storage** to choose the indexing strategy and storage engine.

<Frame caption="Indexing strategy and storage engine settings">
  <img src="/images/new/storage-settings.png" alt="Storage settings with Hybrid retrieval and LanceDB configuration" />
</Frame>

<AccordionGroup>
  <Accordion title="Semantic Search" icon="brain">
    Finds content by meaning. This works well when the question and source use different wording.
  </Accordion>
  <Accordion title="Lexical Search" icon="magnifying-glass">
    Finds exact terms such as names, product codes, identifiers, and specialized vocabulary.
  </Accordion>
  <Accordion title="Hybrid Search" icon="layer-group">
    Combines semantic and lexical retrieval. This is a strong default for mixed business and technical content.
  </Accordion>
</AccordionGroup>

LanceDB can run from a local path, LanceDB Cloud, or S3 compatible storage. Use local mode for development. Choose a persistent remote mode before deploying a knowledge base to a serverless platform.

## General settings

Use **Settings → General** to name the workspace and configure optional web search.

<Frame caption="Workspace and web search settings">
  <img src="/images/new/general-settings.png" alt="General settings with workspace name and web search provider" />
</Frame>

Web search can enrich answers with current information. Select a supported provider and store its API key from this page.

## Installed tool settings

Marketplace tools can add their own provider and processing settings. Open **Settings → Installed Tools** after installing a tool.

<Frame caption="Settings for the installed Video and Audio tool">
  <img src="/images/new/marketplace-tools-settings.png" alt="Installed tool settings for video transcription and frame analysis" />
</Frame>

For example, the Video and Audio tool lets you choose an audio provider, verify its API key, and control the frame extraction interval.

## Agent tools

Use **Settings → Agent Customization** to control which capabilities the assistant can call.

<Frame caption="Choose the tools available to the assistant">
  <img src="/images/new/agent-tools.png" alt="Agent tool controls for search, charts, analysis, forms, and document editing" />
</Frame>

Available tools can include:

- Semantic search over the knowledge base
- Tabular data queries and chart generation
- Python analysis over selected or complete corpus data
- Form filling
- Document editing and signing

Only enable tools that the agent needs for its role.

## Server configuration

After configuring models, storage, and tools, open **Settings → Larkup Server** to launch or deploy the API. See [Deploy Your Server](/developer/deploy) for the current workflow.
